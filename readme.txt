Semantic Certificates for Modulo Schedules with Speculative Predication

Electronic evidence packet: Python checker, two separately implemented
interpreters, exact finite oracles, generated inputs, negative controls,
handwritten proof notes and claim-linked JSON/CSV results.

The implementation supports certified exports and fixed-skeleton annotation
optimization. See README.md for commands, assumptions and supported inputs.
No network access, external services, solver installation or sibling paper
folder is needed for reproduction. The repository is the electronic supplement;
it contains the inputs and results used by the experiments.
