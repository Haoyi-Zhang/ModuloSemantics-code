# Literature access and attribution

`reference-audit.json` and CSV record 35 distinct references used in the
manuscript, their primary identifiers, inspected scope and use locations.
This is a manual first-party cross-check, not a simulated Crossref API run.
Fourteen records identify inspected technical full-text passages; this does
not mean fourteen papers were independently reviewed in their entirety.
Other entries support bibliographic/background or abstract-level scope only.
No private PDF hashes or successful downloads are invented. Third-party PDFs
are not redistributed. In particular, the new HLS entries with unavailable
full text are not evidence of an absence of related results.

The original requested 12-TOPLAS/5-classic/5-neighbor full-text calibration
is not certified by this inventory. The manuscript does not claim an
exhaustive novelty search or that a numerical citation count establishes
journal quality. All 35 entries are cited; no `nocite` padding is used.
